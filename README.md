# lactujeux.github.io

Un site portfolio pour un projet d'arts plastiques — présentation des travaux, expérimentations visuelles et interactions web.

Présentation

Ce site réunit des pages statiques et des scripts légers (HTML, CSS, JavaScript) pour exposer des oeuvres, des articles et des prototypes interactifs. Il sert à documenter le processus créatif et à proposer une navigation simple pour découvrir les pièces et les notes associées.

Fonctionnalités

- Galerie d'images et d'œuvres
- Articles et pages descriptives (ex. articlewd1.html)
- Interactions front-end basiques (home.js, script.js)
- Styles personnalisés dans style.css

Installation et utilisation locale

1. Cloner le dépôt sur votre machine.
2. Ouvrir `index.html` dans un navigateur moderne pour une consultation directe, ou lancer un serveur local :

   python -m http.server 8000

   puis visiter http://localhost:8000

Structure du dépôt

- index.html — page d'accueil
- articlewd1.html — exemple d'article
- home.js, script.js — scripts JavaScript
- style.css — feuille de styles principale
